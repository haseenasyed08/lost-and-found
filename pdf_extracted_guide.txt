1. What you are building
A web platform where people report lost or found objects using text, a photo, a place and
a time. A multi-factor matching engine suggests likely matches, and an item is released
only after private ownership verification. This guide takes you from an empty folder to a
deployed, working site, with code for every core piece.
Must-have (build first): accounts and roles; lost and found reporting; text and image
embeddings; match suggestions with a score breakdown; hidden-detail ownership
verification; handover code; moderator queue.
Stretch: learned ranker (LightGBM); analytics dashboard; email notifications; Hinglish
tuning.
Design rules:
The system suggests matches. It never declares ownership.
Hidden details are encrypted and never sent to a claimant or shown publicly.
Every sensitive action is written to an audit log.
The synthetic dataset I generated earlier (lost_found_dataset.zip) is used for seeding the
demo and for evaluating the matcher.

Request flow
1. User submits a report (form plus optional photo).
2. API validates input, strips photo metadata, blurs faces, stores a public and a private
copy.
3. Embeddings are computed and saved on the report.
4. A background task retrieves candidate reports of the opposite type with pgvector,
then re-ranks them with the multi-factor score.
5. Match rows are created and both users are notified.
6. The owner starts a claim and receives three private questions.
7. Answers are scored: 3 correct approves, 2 goes to a moderator, fewer rejects.
8. On approval the claimant gets a one-time handover code. The finder enters it at
handover and both reports close.

def haversine_m(lat1, lon1, lat2, lon2):
    p1, p2 = math.radians(lat1), math.radians(lat2)
    dphi, dl = p2 - p1, math.radians(lon2 - lon1)
    a = math.sin(dphi / 2) ** 2 + math.cos(p1) * math.cos(p2) * math.sin(dl / 
2) ** 2
    return 2 * 6371000.0 * math.asin(math.sqrt(a))
def cosine(a, b):
    if a is None or b is None:
        return None
    return float(np.dot(np.asarray(a), np.asarray(b)))  # vectors are L2-
normalised
def color_score(a, b):
    if not a or not b:
        return None
    if a == b:
        return 1.0
    return 0.5 if a in COLOR_FAMILY and COLOR_FAMILY.get(a) == 
COLOR_FAMILY.get(b) else 0.0
def brand_score(a, b):
    if not a or not b:
        return 0.5  # unknown is neutral
    return 1.0 if a.lower() == b.lower() else 0.0
def tokens(s):
    return set(re.findall('[a-z0-9]{3,}', (s or '').lower()))
def ocr_score(a, b):
    ta, tb = tokens(a), tokens(b)
    if not ta or not tb:
        return None
    return len(ta & tb) / len(ta | tb)

def pair_components(lost, found):
    d = haversine_m(lost.place.latitude, lost.place.longitude, 
found.place.latitude, found.place.longitude)
    hours = (found.event_time - lost.event_time).total_seconds() / 3600
    earliest = -(lost.time_window_hours / 2 + 2)  # tolerate imprecise lost 
times
    time_s = 0.0 if hours < earliest else math.exp(-max(hours, 0) / 30)
    comp = {
        'text': cosine(lost.txt_emb, found.txt_emb),
        'image': cosine(lost.img_emb, found.img_emb),
        'color': color_score(lost.color, found.color),
        'brand': brand_score(lost.brand, found.brand),
        'geo': math.exp(-d / 250),
        'time': time_s,
        'ocr': ocr_score(lost.ocr_text, found.ocr_text),
    }
    if comp['image'] is None:  # one side has a photo, the other only words

def weighted_score(comp):
    num = den = 0.0
    for k, w in WEIGHTS.items():
        v = comp.get(k)
        if v is None:
            continue  # missing signals are skipped and the rest re-
normalised
        num += w * max(0.0, min(1.0, v))
        den += w
    return num / den if den else 0.0

def candidates(db: Session, rep: Report, k: int = 50):
    opposite = 'found' if rep.type == 'lost' else 'lost'

'open', Report.user_id != rep.user_id)

        q = q.order_by(Report.txt_emb.cosine_distance(rep.txt_emb))

def run_matching(db: Session, report_id: int):
    rep = db.get(Report, report_id)
    if not rep or rep.status != 'open':
        return []
    scored = []
    for other in candidates(db, rep):
        lost, found = (rep, other) if rep.type == 'lost' else (other, rep)
        comp = pair_components(lost, found)
        s = score_pair(comp)
        if s >= settings.MATCH_MIN_SCORE:
            scored.append((lost, found, comp, s))
    scored.sort(key=lambda t: -t[3])
    created = []

Match.found_id == found.id)):

confidence=confidence(s),

v in comp.items()})

def build(split):
    d = P[P.split == split].sort_values('lost_id')
    X, y, groups = [], [], []

13. Security and privacy checklist
Passwords hashed with argon2. Minimum length enforced. Tokens expire (default 2
hours).
Add rate limiting with slowapi to login, register, search and claim routes (for example 5
per minute on login).
Hidden details and claim answers are encrypted with Fernet. Keep the key outside the
repository and back it up separately, because losing it makes stored details
unreadable.
